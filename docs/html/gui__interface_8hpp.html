void handleEmbedding ( const QString & imagePath,
const QString & message,
const QString & savePath,
bool usePVD )

Embed a text message into an image and save the stego-image.

This function takes the user’s message, converts it into a bit sequence (with Hamming error-correction codes), then chooses one of two embedding algorithms—PVD or LSB-DCT—based on usePVD. It writes the resulting stego-image to savePath, and shows an information box telling the user which method was used and how many bits were embedded.

Parameters
imagePathPath to the cover image file (where to hide data).
messageThe text string to embed.
savePathPath where the resulting stego-image will be saved.
usePVDIf true, use the (PVD) algorithm; if false, use (LSB)-DCT.

size_t numBits,

QTextEdit * outputText )

Extract a hidden text message from a stego-image.

Opens the stego-image at imagePath and extracts up to numBits bits using the chosen algorithm (PVD or LSB-DCT). It then applies Hamming decoding to correct any single-bit errors, converts the bits back into a string, and displays it in outputText. If extraction fails or yields no data, a warning box is shown instead.

Parameters
imagePathPath to the stego-image containing hidden data.
numBitsNumber of bits to attempt to extract.
usePVDIf true, use the (PVD) extraction method; if false, use (LSB)-DCT.
outputTextPointer to a QTextEdit where the extracted message will be displayed.
