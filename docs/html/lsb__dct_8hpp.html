void apply_dct_quantization ( cv::Mat & block,
const int quant_table[8][8] )

Apply DCT and quantize a single 8×8 block.

Converts the block to floating point, applies the Discrete Cosine Transform (DCT), then divides each coefficient by the corresponding value in quant_table and rounds to the nearest integer.

Parameters
block[in,out]Input 8×8 pixel block (CV_8U). On output it contains quantized DCT coefficients (CV_32F).
quant_table8×8 matrix of quantization values.

Dequantize and apply inverse DCT to a single 8×8 block.

Multiplies each coefficient in block by the corresponding quant_table value, applies the inverse DCT, then converts the result back to 8-bit pixels.

Parameters
block[in,out]Input 8×8 block of quantized DCT coefficients (CV_32F). On output it contains spatial-domain pixel values (CV_8U).
quant_table8×8 matrix of quantization values used in the forward pass.

size_t embed_lsb_dct ( const std::string & image_path,
const std::vector< uint8_t > message_bits,
const std::string & output_path )

Embed a sequence of bits in the least significant bits of DCT coefficients.

Loads a grayscale image from image_path, splits it into non-overlapping 8×8 blocks, applies DCT and quantization, and hides one bit per AC coefficient by setting its LSB to the next bit in message_bits. After embedding all bits (or reaching the image boundary), applies inverse DCT and saves the result.

Parameters
image_pathPath to the cover image (grayscale PNG, JPEG, etc.).
message_bitsVector of bits (0 or 1) to embed.
output_pathPath where the stego-image will be written.
Returns
Number of bits actually embedded (equals message_bits.size() if all fit; returns 0 if the image failed to load or message_bits is empty).

std::vector< uint8_t > extract_lsb_dct ( const std::string & stego_path,
size_t num_bits )

Extract a sequence of bits from the LSBs of DCT coefficients.

Loads a grayscale stego-image from stego_path, splits it into 8×8 blocks, applies DCT and quantization, then reads the LSB of each AC coefficient in block-order until num_bits bits have been collected or the image ends.

Parameters
stego_pathPath to the stego-image with hidden data.
num_bitsNumber of bits to extract.
Returns
Vector of extracted bits. If the image cannot be read or fewer than num_bits bits are available, the return will be empty or shorter than num_bits.
